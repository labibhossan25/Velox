# YAF Development - AI Digital Product Studio

A premium, motion-rich agency portfolio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Deploy to Vercel (Free Hosting)

This site is already configured for **Vercel** - the free hosting platform you mentioned!

### Quick Deploy Steps:

1. **Push your code to GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPO_URL
   git push -u origin main
   ```

2. **Connect to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Sign up/Login with GitHub
   - Click "New Project"
   - Import your GitHub repository
   - Vercel will auto-detect it's a Vite/React project
   - Click "Deploy"

3. **That's it!** Your site will be live in ~2 minutes with a free `.vercel.app` domain

### Custom Domain (Optional)
- In Vercel dashboard → Settings → Domains
- Add your custom domain
- Follow DNS instructions
